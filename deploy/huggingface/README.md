# JARVIS: AI Inbox Agent for Erasmus Coordinators

A hackathon prototype built with Python, Google ADK and Gemini. It reads Erasmus applications, checks eligibility with fixed rules, suggests partner universities and drafts replies for a coordinator to approve. The agent has no way to send email.

**About this demo:** all data is fake sample data. To keep it free to run, it plays back a saved real Gemini run instead of calling Gemini live, and the FAQ chatbot answers only its sample questions. Everyone who opens the demo shares the same results, so press "Start over" to begin again.
